# Panayotis Kola — personal site

Live at **[panoskola.github.io](https://panoskola.github.io)**.

Static site for GitHub Pages. No build step: HTML, CSS and vanilla JavaScript.

- `index.html` — page structure
- `assets/css/style.css` — styles, dark/light themes
- `assets/js/content.js` — all text (English + Greek). Edit content here.
- `assets/js/main.js` — rendering, language/theme switch, animated network background, interactive terminal
- `assets/cv/Panayotis_Kola_CV.pdf` — downloadable CV
- `assets/img/` — logo and social preview image
- `assets/fonts/` — self-hosted Commissioner and JetBrains Mono (SIL Open Font License), Latin and Greek subsets

Press <kbd>`</kbd> on the site to open the terminal.

Visitor statistics come from my self-hosted Umami instance — see
[site-analytics](https://github.com/panoskola/site-analytics).
